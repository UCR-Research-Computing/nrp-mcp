# Code of Conduct

We want this project to be a welcoming place for researchers, students and engineers of
every background and level of experience.

## Expected behavior

- Be kind and patient, especially with people new to Kubernetes or research computing.
- Assume good intent; critique ideas, not people.
- Respect differing views and experience.

## Unacceptable behavior

Harassment, insults, discriminatory language, personal attacks, publishing others' private
information, and any conduct that would be inappropriate in a professional setting.

## Enforcement

Report concerns to research-computing@ucr.edu. Maintainers will review every report, keep
it confidential, and may remove content or contributors that break this code.

This code is adapted from the [Contributor Covenant](https://www.contributor-covenant.org/),
version 2.1.
