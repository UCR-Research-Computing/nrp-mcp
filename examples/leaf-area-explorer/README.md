# Leaf area explorer (example)

A tiny Streamlit app with synthetic data, used to test `nrp_plan goal=web`.

Ask your assistant: *"Put the app in examples/leaf-area-explorer on the web."* nrp-mcp
detects Streamlit (port 8501), suggests names such as `leaf-area-explorer.nrp-nautilus.io`,
and publishes only after you type the URL back. Remove it with *"clean up"*.
