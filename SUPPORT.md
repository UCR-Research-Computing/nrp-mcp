# Getting help

- **First-time setup and troubleshooting:** read [docs/START-HERE.md](docs/START-HERE.md) and
  run `nrp-mcp doctor` (paste its output when asking for help; it never prints secrets).
- **Using nrp-mcp:** open a [GitHub issue](https://github.com/UCR-Research-Computing/nrp-mcp/issues)
  (question or bug).
- **UCR researchers:** research-computing@ucr.edu, and the
  [Nautilus guides](https://ucr-research-computing.github.io/kb/kb023-nautilus-researcher-guide/).
- **The Nautilus cluster itself** (accounts, namespaces, quotas, outages): the NRP's Matrix
  community support chat and documentation at https://nrp.ai/contact.
